# Fundamentals of Data Science Lab Experiments

This repository contains the laboratory experiments performed as part of the Fundamentals of Data Science course using Python.

## Topics Covered
- Data Analysis and Data Preprocessing
- Data Visualization
- Data Collection and Exploration
- Statistical Analysis and Hypothesis Testing
- Data Cleaning and Feature Scaling
- Machine Learning Algorithms

## Tools Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Experiments
This repository includes experiment records in PDF format covering the concepts listed above.

## Objective
To gain practical knowledge of data science concepts and techniques through hands-on experiments.
